# CBRT India TWG — Stakeholder Mind Map

Interactive mind map of the India Technical Working Group (TWG) candidate members for Climate Bonds Resilience Taxonomy (CBRT) criteria development.

**Programme:** Climate Bonds Initiative · USISA Programme  
**Contact:** Jay Shah · May 2026  
**Sectors:** 5 | **Candidates:** 50

## Sectors Covered

| Code | Sector |
|------|--------|
| MFA-1 | Agriculture — Crop Production |
| MFA-3 | Agriculture — Livestock |
| MFA-2 | Urban Systems |
| COOP-1 | Buildings & Construction |
| MFA-4 | Energy Infrastructure |

## Features

- 🗺 **Interactive mind map** — zoom, pan, click to explore
- 🔍 **Search** — find members by name, organisation, expertise (⌘K)
- 📋 **Detail panels** — full member profiles with contact info
- 🏆 **Tier system** — visual hierarchy: Anchors, Core, Technical, Advisory
- 📱 **Responsive** — works on desktop and tablet

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deploy to Vercel

Connect this repository to Vercel and deploy. No environment variables required.

```bash
npm run build  # verify build before deploying
```
